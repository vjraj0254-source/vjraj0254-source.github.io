# Vijay Raj Venugopal — Portfolio Website

> **Live Site:** https://vjraj0254-source.github.io

A professional engineering portfolio website built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies, blazing fast.

## About This Portfolio

This portfolio showcases the work of **Vijay Raj Venugopal**, a Mechanical Engineer specializing in:
- Gas pipeline construction & field engineering
- Autonomous robotics (ROS2, SLAM, Navigation2)
- Mechanical systems design
- Six Sigma process optimization

## Features

- ⚡ Animated blueprint grid hero background with parallax
- 🤖 Typing effect cycling through engineering roles
- 📊 Interactive skill bars with scroll-triggered animations
- ⏳ Expandable experience timeline (color-coded by domain)
- 🃏 3D tilt project cards with modal detail overlays
- 🏅 Certification badge grid with shimmer hover effects
- 📄 Inline resume PDF viewer + mobile-friendly fallback
- 🔗 Connect section with clipboard copy and dynamic accent colors
- 📬 Formspree-powered contact form with success state
- 🌓 Dark/light mode toggle (persisted in localStorage)
- 🎯 Custom engineering crosshair cursor
- 📈 Scroll progress indicator
- ♿ ARIA labels, semantic HTML5, keyboard navigation

## Setup

1. **Place your resume PDF** at `assets/resume/Vijay_Raj_Venugopal_Resume.pdf` (exact filename required)
2. **Update GitHub username** in the GitHub connect card in `index.html` (search for `vijayrajvenugopal`)
3. **Set up Formspree** — see instructions in index.html comments
4. **Set up Calendly** — see instructions in the Schedule a Chat card
5. Push to GitHub and enable GitHub Pages
